# Harbour Freight engagement workspace (Northwind Consulting)

Rules for anyone, human or agent, working in this folder.

## Folders

- `Input/` is read-only. Source material: transcripts, recordings, client documents. Never edit, move or delete anything in it.
- `Output/` is free. Drafts, recaps and working files go here.
- `Artefacts/` is governed. It holds the published, reviewed records (stakeholder list, promoted recaps). Ask the user before writing to it. Never write there on your own.

## Meetings

- Recaps live in `Output/Meetings/<YYYYMMDD_Slug>/`, named after the meeting folder in `Input/Meetings/`.
- Client-safe copies go to `Output/Meetings/Sanitised/`.
- Promotion means copying a verified recap into `Artefacts/Meetings/`. Only do it when the user says "promote".
- Every recap starts with the internal banner as its first line: **Internal to Northwind Consulting. Not for Harbour Freight distribution.**

## Names and terms

- `Glossary.md` in this folder's root is the single glossary. Keep it current. Never create a second glossary file.
- `Artefacts/Stakeholders/stakeholders.md` is the authority for how people's names are spelled.
- Banned name: the programme's old name, "Project Kestrel". It is now "Tidewater". Never write the old name in any file you produce, not even inside a quote or as "formerly".

## The user

The user is Callum Reeve, Engagement Lead at Northwind Consulting. He often works away from his desk, so when a call is defensible, make it and say what you assumed.
