# Gap Why It Matters Severity Workstream
SAP-01 SAP condition type for the rebate credit is undefined
FR_Q12 asks for a rebate credit on the quote but names no SAP condition type or document type, so the pricing payload cannot be built.		 The vendor cannot start the pricing integration until the SAP team names the condition type. Critical WS5
CTR-01 Account volume contradicts the RFP
RFP §3 sizes the platform for 1,200 customer accounts; NFR-P02 sizes it for 200.		 Quote and settlement capacity are priced on different volumes. High WS5
BPM-01 Quote validation has no failure path
Task_ValidateQuote has a single outgoing flow, so a rejected quote has nowhere to go (FR_Q12).		 A rejected quote silently stalls. Medium WS5
