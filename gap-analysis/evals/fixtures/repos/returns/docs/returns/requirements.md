# Returns Handling: Requirements (synthetic excerpt)

| ID | Requirement |
|----|-------------|
| FR_R01 | A customer can request a return within 30 days of delivery. |
| FR_R02 | A support agent checks the request against the returns policy. |
| FR_R03 | An approved request is issued a return authorisation code that the customer quotes on the parcel. |
| FR_R04 | The warehouse inspects the returned goods against the return authorisation code. |
| FR_R05 | A re-stock charge is deducted from the refund when the goods are opened. |
| FR_R06 | The refund is paid to the original payment method within 5 working days of inspection. |
